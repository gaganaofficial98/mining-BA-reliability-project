## Methodology (read this before the table — it's the honest part)

**How postings were found:** Direct searches and fetches against public job-board and employer career-site URLs on 1 October 2026 — `au.indeed.com` aggregator search-result pages (`au.indeed.com/q-business-analyst-l-perth-wa-jobs.html` and `au.indeed.com/q-data-analysis-in-mining-jobs.html`), plus direct fetches of individual employer career pages (`miningcareers.com.au`, `dealertechjobs.caterpillar.com`, `careers.apm.net.au`) where those were reachable.

**[ASSUMPTION / LIMITATION — disclosed, not hidden]** `au.seek.com` — the single largest Australian job board and the one most BAs would check first — actively blocks automated fetching (returned HTTP 403 on every attempt). This matrix is therefore built from Indeed's aggregator listings and individually-fetched employer career pages, not from a SEEK search. That's a narrower net than a human job-hunter would cast, and it means some strong, currently-live Perth mining-BA roles on SEEK are not reflected here. A thorough version of this exercise would repeat it manually against SEEK.

**[CITED SOURCE — status disclosed per posting]** Of the postings quoted below, several are no longer accepting applications as of the fetch date: the Macmahon and APM listings are marked "expired" on their own pages, and the Pilbara Ports Authority listing states it closed 13 September 2026. These are included anyway because the *requirement language itself* — written by a real mining-sector employer for a real role — is the evidence being used, not a claim that the vacancy is currently open. Each row below states the posting's status plainly. The WesTrac/Caterpillar listing (Ref #4787) showed no expiry date at fetch time and is treated as the most likely to be current, though "no expiry date shown" is not the same as a confirmed-open guarantee.

**Why this matters for the project's honesty standard:** it would be easy to only quote the flattering, currently-open postings and imply a cleaner story than the data supports. The point of this matrix isn't "look, there are 12 open jobs waiting" — it's "here is real language real mining employers use to describe this work, and here is exactly where this project demonstrates each thing." A skeptical recruiter checking these URLs should find exactly what's described here, including the "expired" banners.

**Databricks question — resolved here, not before:** `Reconciled-Finish-Schedule.md` (30 Sept 2026 discussion) left open whether Module A (the optional classical ML Proof-of-Concept) should carry a footnote positioning it against Databricks, since several mining-sector data-engineering postings mention cloud data platforms, and named this Job-Fit Matrix task as the evidence-gated decision point. **Decision: no footnote added.** Across the 17 real postings reviewed while sourcing this matrix (the 12 quoted in the table below, plus 5 more reviewed and not included because they didn't map cleanly to a specific deliverable), not one mentions Databricks, Snowflake, or any specific cloud data platform by name — the closest is generic "cloud platforms" in a Whitehaven Coal graduate-data-engineer posting, which is a data engineering role, not a BA/analyst role, and outside this project's job-fit target. Per the schedule's own rule (only add the footnote if real postings justify it), the evidence doesn't justify it. Module A's write-up will note scikit-learn/pandas as the honest, demonstrable choice and will not claim Databricks familiarity.

## What this matrix does and doesn't prove

It doesn't prove any of these specific employers would hire Gagana for any of these specific roles — that's not a claim this document makes. What it does show is that the deliverables already built in this project aren't a generic "BA 101" exercise invented in isolation; the language used by real mining-sector employers in late-2026 Perth postings — ERP/fleet/maintenance-system integration, Power BI/SQL reporting, AI-assisted development practices, stakeholder-driven requirements work — maps directly onto specific, named, inspectable files in this repo. A recruiter can open any of the twelve source URLs and check the quote against this table.

**Limitation carried forward honestly:** 5 of the 12 rows above come from postings that are expired or closed at the time of fetching. This is disclosed above, not smoothed over. The strongest *currently-live* evidence in this matrix is the WesTrac/Caterpillar Asset Management Analyst posting (rows 6–8) and the Bravo Search / MNG listings (rows 9, 10, 12), which together already cover the project's core claims (maintenance-system fit, BI/reporting fit, stakeholder/requirements fit) without needing the expired postings at all.
