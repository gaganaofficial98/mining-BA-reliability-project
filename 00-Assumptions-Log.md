# 00 — Assumptions Log

**Owner:** Gagana Suresh
**Purpose:** Per `00-Master-Plan.md`'s own Day 1 instruction and "Next steps" item 3, a running record of every labeled assumption used anywhere in this project — the explicit, cited, or disclosed fill-ins that stand in for facts the AI4I 2020 dataset itself cannot provide. Per the standing principle in `Scope-Decisions-and-Limitations-Log.md` ("labeled assumptions vs. circular assumptions"): a labeled assumption is valid when it fills in a fact genuinely external to the dataset; it becomes illegitimate the moment it assumes the answer to the exact question the analysis is supposed to derive.

**Reconstruction note (1 October 2026):** this document was supposed to be live from Day 1 of the project (Master Plan, Section "Next steps," item 3) but was never actually brought into this Project's shared workspace, even though three other documents — `Scope-Decisions-and-Limitations-Log.md`, `05-Data-Dictionary.md`, and the Reconciled-Finish-Schedule — all cite specific numbered items in it (most notably "item #5," the downtime-cost-per-hour benchmark) as if it already existed. This gap was caught during this project's final cross-document consistency audit (1 Oct 2026), not before — logged here plainly rather than quietly patched, consistent with this project's own error-disclosure convention (`Prompt-Library.md`, Entries 8 and 9). What follows is reconstructed directly from the decisions already fully documented and dated in `Scope-Decisions-and-Limitations-Log.md`, numbered so that existing cross-references (in particular, item #5) land correctly — it is not new analysis, only the compiled index this project should have had from Day 1.
